# Shellforge – OSSP Course Project

**Roll Number:** 2520030537
**Project:** ForgeOS – Shellforge
**Language:** C

## About the Project

Shellforge is a custom Unix-style shell developed in C as part of the Operating Systems and System Programming (OSSP) course.

## Features

* Personalized shell prompt
* Execute Linux commands using `fork()` and `execvp()`
* Built-in commands: `cd`, `help` and `exit`
* Process synchronization using `waitpid()`

## Compilation

```bash
gcc myshell.c -o myshell
```

## Execution

```bash
./myshell
```
